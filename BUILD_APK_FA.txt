ساخت APK با Android Studio

۱) Android Studio را روی کامپیوتر نصب کن.
۲) فایل ZIP پروژه را از حالت فشرده خارج کن.
۳) از Android Studio گزینه Open را بزن و پوشه android_project را انتخاب کن.
۴) صبر کن Gradle Sync کامل شود و اگر SDK Platform 35 خواست، آن را نصب کن.
۵) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کن.
۶) فایل خروجی معمولاً در مسیر زیر است:
   app/build/outputs/apk/debug/app-debug.apk

نصب روی گوشی:
- فایل app-debug.apk را به گوشی منتقل کن و بازش کن.
- اگر اندروید اجازه خواست، برای برنامه‌ای که فایل را باز می‌کند اجازه Install unknown apps را فعال کن.
- پس از نصب، آیکن Pixel Planner در فهرست برنامه‌ها ظاهر می‌شود؛ معمولاً می‌توانی آن را نگه داری و به Home screen بکشی.
- اندروید نصب برنامه را معمولاً به‌طور خودکار روی صفحه اصلی نمی‌گذارد؛ این رفتار به لانچر گوشی بستگی دارد.

این بسته سورس پروژه اندروید است، نه APK کامپایل‌شده. محیط فعلی ابزار Android SDK/Gradle لازم برای ساخت و امضای APK را ندارد.
